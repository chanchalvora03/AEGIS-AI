# AEGIS

## Failure-Driven Self-Evolving AI System

AEGIS is an adaptive AI system designed to identify its own failures, analyse their root causes, learn from past mistakes, and adapt its problem-solving workflow.

### Core Flow

Input → Generate → Evaluate → Detect Failure → Diagnose → Check Failure Memory → Adapt Workflow → Generate Improved Response

### Key Features

- Failure detection and classification
- Root cause analysis
- Failure memory
- Similarity-based retrieval of past failures
- Adaptive agent workflow
- Self-repair and response improvement
- AI health and failure reports
